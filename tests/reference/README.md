# Official Reference Fixtures

`official_3cf7d870.json` contains small deterministic outputs generated by executing source from
the official CenterPoint commit pinned in `docs/BASELINE.md`. The fixture covers Gaussian drawing,
box corners, ordered voxelization, mean voxel encoding, focal and regression losses, target
assignment, dense pre-NMS decoding, and the canonical configuration manifest.

Regenerate it from a clean checkout at the pinned commit:

```bash
python tests/reference/generate_official_fixtures.py /path/to/official/CenterPoint \
  > tests/fixtures/official_3cf7d870.json
```

The generator verifies both the checkout commit and a clean working tree before producing output.
It isolates the relevant historical modules so CUDA extensions and the complete legacy training
environment are not needed.
